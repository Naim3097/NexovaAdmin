# SOP 2 — Weekly AM Cadence

**Owner:** every Account Manager, for each client they own · **Cadence:** Mon + Thu

## Monday — generate & chase

1. Open **Reports → Weekly updates** (nexops.my/reports/weekly), pick your client.
   The update drafts itself from live data: completed last 7 days, in progress,
   waiting-for (with how long the client has been sitting on it), next week,
   issues (overdue invoices, quota overage).
2. Read the **Waiting for** section — everything there is your Monday chase list.
   Chase the client on anything older than 3 days.
3. Fix anything that looks wrong *in the system, not in the message* — if a stage
   is actually done, mark it done; the report reflects reality only if the boards do.

## Thursday — send & book

4. Re-open the weekly update, hit **Copy**, paste into WhatsApp, add one human
   line on top (the personal read only you have). Send.
5. If anything needs a call, book it now for next week — don't leave it floating.

## Rules

- The update is generated from the system every time. Never hand-write the list —
  if the system's list is wrong, the boards are wrong; fix the boards.
- Renewal pings (30d / 7d / day-of) arrive in Telegram — the AM who owns the
  client opens the renewal conversation the same day the 30-day ping lands.
