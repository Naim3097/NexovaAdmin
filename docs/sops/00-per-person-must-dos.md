# Per-Person MUST-DOs — Operating Nexov Admin as Intended

The full workflow, end to end: **lead obtained → qualified → presentation →
quotation → closed (won) → deposit invoice → paid → client onboarded → kickoff →
strategy → production → QC → client approval → live → report → weekly update →
invoice monthly → renewal**. Every arrow below names who moves it and where the
trace lives. If a step isn't in the system, it didn't happen.

---

## Naim — Sales / CEO · AM: Lean.x, Nexova, Payright MY, KALIMA, Fynecta, Temenggor

**Per lead (the moment one appears, any source):**
1. Enter it in **Leads** the same day — name, company, est. value, source. No
   lead lives only in WhatsApp/DMs.
2. Move its status as it progresses: qualified → presentation → quotation.
3. Quotation stage = issue the quote **from the system** (Quotes → new, PDF,
   send). Not a Canva/Word file.
4. Won = two clicks, same sitting: **Create deposit invoice** (on the lead) →
   **Promote to client**. Work never starts before the deposit invoice is paid.
5. Lost = mark lost with one honest note (future sales intel).

**Weekly (as AM):** Mon — open Reports → Weekly updates for each of your
clients, chase everything in "Waiting for". Thu — copy, add one human line,
send via WhatsApp. Renewal ping in Telegram = you open the renewal
conversation that same day.

**As CEO:** decide on +14-day overdue invoices (escalate or pause — SOP 5);
answer "should we have billed this?" only from the dashboard, never from memory.

## Farisha — Admin / Finance (second system admin in training)

**Per new client (SOP 1):** deposit invoice paid → complete the client record
(contacts, AM, package name, retainer MYR, monthly quota, revision limit,
extras pricing, **renewal date**) → portal invite → Sprint Task "Kickoff
<client>" to Danisy.

the content board flags). By the 3rd — ALL of them sent. A draft bills nobody.

collection ladder off A/R aging (due-date nudge → +7d AM escalation → +14d

status churned → reason noted.

**As admin #2 (SOP 7):** practice invites, password resets, contact swaps —
the test is that ops never stalls when Danisy is away.

## Danisy — PM / Ops Lead · AM: Tropicor · System admin

**Daily:** triage **Sprint Tasks** — re-route wrong PICs, merge duplicates,
convert misfiled requests into project stages. Anything someone WhatsApps you
that is actually work: reply "board it" (SOP 4).

**Per kickoff:** create the project; **every stage gets a PIC and a due date
at creation** — the deadline bot can only chase dates that exist.

done; dates that slipped get re-dated (never silently ignored). Plus Mon/Thu
weekly update for Tropicor.

**Ads / Website / SEO (your delivery lanes):** ad campaigns live in
**Campaigns** — create each one, log spend/metrics there (reports and client
updates read from it). SEO work moves through **SEO articles** (brief →
outline → body → published). Website builds run as project stages with due
dates, pulling Zafran in for backend stages.

**As admin:** invites/resets/contact changes (SOP 7) — and train Farisha on
each until she can run them alone.

## Everyone — the four habits that make the system real

1. **Telegram pings are assignments, not FYIs.** Due-tomorrow ping → done
   tomorrow, or the date gets changed openly on the board.
2. **If you'd WhatsApp a request, board it instead** (Sprint Task, PIC,
   deadline — default 3 days).
3. **Done means marked done in the system** — not announced in chat.
4. **Client-facing review happens in the portal** — drafts, feedback and
   approvals over WhatsApp don't count against quota or revisions and are
   invisible to billing.
