# SOP 5 — Invoicing & Collections

**Owner:** Farisha · **Board:** nexops.my/invoices (A/R aging on Reports)

## Monthly retainer run — 1st of the month

1. For every active client with a monthly retainer set on their record, create
   the month's invoice (retainer line + any billable extras carried over from
   quota overage / extra revisions — the content board flags these).
2. **Send by the 3rd.** A draft invoice bills nobody — the audit found 5 of 8
   invoices stuck in draft. Draft → Sent same sitting, or don't create it yet.
3. Attach the payment link (LeanX FPX once KYC clears; bank transfer details
   render on the PDF meanwhile).

## Collections — off the A/R aging report (Reports)

- **Due date passed:** polite WhatsApp nudge from Farisha, same day the
  overdue Telegram ping lands.
- **+7 days:** AM raises it personally with their client contact.
- **+14 days:** Naim decides — escalate or pause work. Pausing is a
  Naim-level call, never automatic.
- Log every chase as a note on the invoice so the trail is in one place.

## Deposits (new clients)

Deposit invoices come from the won lead (SOP 1). Same rule: send immediately,
work starts only on **Paid**.

## Rules

- Mark **Paid** the day money lands — dashboards, weekly updates, and renewal
  conversations all read from this.
- If a client's retainer/extras aren't configured on their record, fix the
  record first (that's the billing source of truth), then invoice.
