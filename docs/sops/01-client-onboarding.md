# SOP 1 — Client Onboarding

**Owner:** Farisha · **Trigger:** a lead is marked **Won** (deposit agreed)

## Steps

1. **Deposit invoice** — on the lead page → Actions → **Create deposit invoice**.
   The system drafts an invoice at 50% of the estimated value. Review the line,
   adjust if the agreed deposit differs, set due date (default: 7 days), **Send**.
2. **Wait for deposit paid** before any production starts. Mark the invoice
   **Paid** the moment money lands (this is the playbook's closing rule — the
   system now represents it).
3. **Client record** — lead page → **Promote to client** (reuses an existing
   record if the name matches). Then on the client profile fill in, same sitting:
   - Contact name / email / phone
   - **Account manager** (per the AM ownership list)
   - **Service package**: package name, monthly retainer (MYR), monthly content
     quota, revision limit, extras pricing, **package renews on** date
4. **Portal invite** — client profile → Portal access → invite with the client's
   email. Share the set-password link via WhatsApp. Confirm they can log in at
   nexops.my → Client Login.
5. **Kickoff** — notify Ops (Danisy) via a Sprint Task: "Kickoff <client>",
   PIC = Danisy, deadline = 3 days. Danisy creates the project; every stage gets
   a due date at creation (see SOP 4 and the stage-deadline bot).

## Done when

Client record complete (AM + retainer + quota + renewal date), deposit invoice
paid, portal login verified, kickoff project exists with dated stages.
