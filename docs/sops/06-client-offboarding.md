# SOP 6 — Client Offboarding

**Owner:** Farisha (with the client's AM) · **Trigger:** non-renewal confirmed,
churn, or contract end

## Steps

1. **Final invoice** — bill outstanding work: current month pro-rata, unbilled
   extras (quota overage, billable revisions — the content board has the counts).
   Send before access changes so goodwill is intact while you collect.
2. **Handover package** — export/collect for the client: final approved content
   files, account credentials they own, performance reports. Deliver via the
   portal or a shared folder; note delivery on the client record.
3. **Portal access** — after final payment clears, revoke the client's portal
   login (client profile → portal access). Don't delete the client record.
4. **Client record → status `churned`** (or `paused` if it's a pause). Keep all
   history — content, invoices, projects stay queryable for reactivation.
5. **Contact swap variant** (the LZS case): if the client stays but the person
   changes, don't offboard — change the auth email on the existing login via
   System Admin (SOP 7). All history stays with the new contact.
6. **Close the loop** — cancel open project stages, close open content cards,
   remove the client from the AM's weekly cadence. Note the churn reason on the
   client record (one honest sentence — future sales intel).

## Done when

Final invoice paid, handover delivered, portal revoked, status set, churn
reason recorded.
